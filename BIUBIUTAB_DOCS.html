BiuBiu Tab — 技術與功能文檔

版本 v1.3 · 2026-05-23 · github.com/unknownseed/biubiutab

BiuBiu Tab 是一款 AI 吉他製譜與教學桌面應用，搭配官方介紹網站。使用者可上傳音頻或 YouTube 連結，經由本地 AI 自動生成 Guitar Pro 5 (.gp5) 吉他譜，並在桌面端進行跟彈練習與模組化教學。

處理 Pipeline

音頻輸入（本地 / R2 / URL）
  │
  ├── 1. yt-dlp 下載（URL 模式）
  ├── 2. Demucs 音源分離 (vocals/drums/bass/other/no_vocals)
  ├── 3. Faster-Whisper → 歌詞
  │     └── DeepSeek API 歌詞驗證（可選）
  ├── 4. Basic Pitch → MIDI 旋律
  ├── 5. Madmom / Librosa → 和弦
  ├── 6. 節奏動機 + 段落識別
  ├── 7. 風格融合 + 聲部優化
  ├── 8. PyGuitarPro → .gp5
  └── 9. 儲存（本地或 R2）
